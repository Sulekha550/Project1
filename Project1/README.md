# Task 1 - Responsive Landing Page

A clean and modern responsive landing page built using HTML5 and CSS3.

## Features
- Responsive navigation
- Hero section with CTA
- Features section
- About section
- Contact CTA
- Footer with social links
- Flexbox and CSS Grid
- Media queries
- Mobile, tablet and desktop responsive layout

## Technologies
- HTML5
- CSS3
- Flexbox
- CSS Grid
- Media Queries
- Responsive Web Design

## How to Run
1. Open the folder in VS Code.
2. Install the Live Server extension.
3. Right-click `index.html`.
4. Select **Open with Live Server**.
5. Resize the browser window to test responsiveness.

## Project Structure
- `index.html` - webpage structure
- `style.css` - styling and responsive layout

## Learning Outcome
This project demonstrates semantic HTML, CSS layout, Flexbox, Grid, media queries, responsive design, positioning and basic UI design.
